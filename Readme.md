# 🌑 ShadowChat

ShadowChat is a full-stack social platform inspired by Reddit, designed to bring together community-driven discussions, real-time communication, and device management in a single application.

Users can create and manage communities, share posts, participate in discussions through comments, and engage with content using likes and other social interactions. Each user has a dedicated profile that showcases their activity and contributions across the platform.

Beyond traditional community interactions, ShadowChat features real-time chatrooms that enable seamless communication between members, creating a dynamic and engaging social experience.

---

## ✨ Features

### 👤 User Management

* User registration and authentication
* Personalized user profiles
* Profile activity tracking
* Account settings management

### 🌐 Communities

* Create and manage communities
* Join and participate in communities
* Community-based discussions and content sharing
* Community moderation capabilities

### 📝 Posts & Engagement

* Create, edit, and delete posts
* Like and interact with posts
* Comment on discussions
* Community-driven content engagement

### 💬 Real-Time Chatrooms

* Create chatrooms
* Join community chatrooms
* Real-time messaging and communication
* Group discussions and collaboration

### 📱 Device Inventory

* Track and manage personal devices
* Maintain device records and information
* Organized device inventory dashboard

### ⚙️ Platform Features

* Responsive user interface
* Modern social platform architecture
* Scalable backend design
* Extensible feature structure for future enhancements

## 🎯 Project Goal

ShadowChat aims to combine the best aspects of online communities and real-time communication into a single platform. The project focuses on enabling meaningful discussions, fostering community engagement, and providing users with additional productivity tools such as device inventory management.
